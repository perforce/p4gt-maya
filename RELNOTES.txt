Installing P4GT

	To install P4GT Maya 2025.1, download the P4GT Maya 2025.1 installer from
	the P4 website and run it.  The P4GT English plug-in is only
	compatible with English version of Maya.

	P4GT Maya is compatible with:

	* Autodesk Maya 64-bit 2026

	P4GT is available on Windows 10, 11 for Intel (x64),

	Windows Server 2012, 2016, 2019 and 2022.

	You can use P4GT with minimum supported P4 server version or higher.

Loading the P4 menu in Maya

	After installing P4GT Maya, you must configure Autodesk Maya to load the P4 
	menu as follows:
	
	1. In Maya, choose Windows>Settings/Preferences>Plug-in Manager.  
	
	2. In the Plug-in Manager dialog, type "P4GT" to find P4GT-Maya-2026_x64.mll
	   and check "Loaded", then select "Auto-Load."
